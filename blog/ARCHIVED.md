# Archived: `blog/`

An early Rails blog-engine prototype generated by `rails new`.

## Status

**Not built, not tested, not deployed, not maintained.** No CI job, Gemfile or
lockfile touches this directory. It exists only as a historical record of the
project's 2011-era starting point.

## Do not start here

There is no `Gemfile.lock` here, so `bundle install` resolves fresh versions of
unpinned gems against a Rails 4.0-era dependency set and will not produce a
working install. The maintained application is [`../todo/`](../todo/).

If you need to work on this code, first give it a lockfile and a passing test
suite, then move it under `todo/`'s CI. Do not deploy it in its current state.
